# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub Issues or
Discussions.

If you discover a security vulnerability affecting OUxInfo or its project
infrastructure, contact the repository maintainer privately.

Public Issues should be used for ordinary bugs, numerical problems,
performance issues, feature requests, and validation problems.

## Scope

Security reports may include vulnerabilities in GitHub Actions, package/build
infrastructure, dependency handling, documentation deployment, or release
infrastructure.

Ordinary numerical or scientific implementation errors should be reported
through the appropriate public Issue template.
